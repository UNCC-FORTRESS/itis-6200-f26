# Archive — designs that don't match what actually shipped

These 9 lab folders were built (mostly in one bulk commit, 2025-12-28) but are **not** what ran as the corresponding lab in Spring 2026, confirmed by directly reading the real Canvas assignment `.docx` files. They're kept, not deleted, because the tools themselves are well-built and several are already cited as optional starter material in the Fall 2026 project catalog (private `3200-6200-8200-grading-keys` repo, `ta-prep-fall2026/project-guidelines/`). See that same private repo's `ta-prep-fall2026/COURSE_MATERIALS_MAP.md` for the full investigation.

| Folder | Why it's archived |
|---|---|
| `Lab03_HashesMACs/` | Real Lab 03 = a combined Authenticated-Encryption-schemes + Diffie-Hellman/PRNG-rollback + Mallory-MITM-programming lab, delivered via CyberChef + a Python template, not this folder's `HashLab.html`/`MiniHashCollider.html`. |
| `Lab03_05_MegaLab/` | Same real Lab 03 as above — this folder's `LedgerLab.html`/`KeyExchangeSim.html`/`CryptoMessenger.html` combo also never shipped. Neither Lab03 design (this one or `Lab03_HashesMACs`) is the real lab; both are archived, not just one. |
| `Lab04_PRNG_DH/` | Real Lab 04 = RSA keygen/encrypt, digital signatures, hybrid encryption, a certificate-chain-of-trust conceptual section, and a password-salting timing simulation — all via CyberChef + a Python/Colab notebook. This folder's DH/PRNG content actually shipped as **part of Lab 03**, not as its own Lab 04. |
| `Lab05_RSA/` | Real Lab 05 = the Bell-LaPadula access-control visualizer (`BLP.py`/`Cases.py`, see the new `../Lab05_AccessControl_BLP/`) plus web-origin/cookie/CSRF theory questions. RSA (this folder's actual topic) shipped as **Lab 04** instead, via CyberChef, not `RSACalc.html`/`RSALab.html`. |
| `Lab06_CertsPasswords/` | Real Lab 06 = **DVWA penetration testing** (CSRF/SQLi/reflected+stored XSS, hands-on exploitation in a VM) — see the new `../Lab06_DVWA_PenTest/`. This folder's certificate-authority/password-cracking tools (`CertAuthorityTool.html`, `CertLab.html`, `CrackLab.html`, `HashCracker.html`) relate to concepts that appear only as **written questions inside Lab 04** (certificate chain-of-trust, password salting) — never their own numbered lab. Kept as optional interactive supplements for that section. |
| `Lab07_AccessControl/` | Real Lab 07 = **Network Traffic Analysis** (ARP via Wireshark, the third-party NetLab simulator at netlab.thecybersecguru.com, TELNET vs. SSH comparison, TCP three-way handshake, Python socket programming) — see the new `../Lab07_NetworkTrafficAnalysis/`. This folder's RBAC/ABAC tool (`AccessControlSim.html`) was never deployed under any lab number; access control shipped as the **BLP model in Lab 05** instead. Still directly useful — Grad Project #7 in the project catalog is built around exactly this ABAC-vs-BLP contrast. |
| `Lab08_WebIntro/` | Real Lab 08 = **Memory Safety** (buffer overflow/shellcode placement via the repo's own `memsafety.html`, see the new `../Lab08_MemorySafety/`) — not Web Intro. This folder's cookie/CSRF tools (`CookieShop.html`, `CSRF_Simulation.html`, `WebLab.html`) cover material that actually shipped as **part of Lab 05's** origin/cookie/CSRF theory questions, with the hands-on CSRF/XSS exploitation happening separately in **Lab 06's** DVWA exercise. Kept as optional interactive supplements for Lab 05. |
| `Lab09_WebAttacks/` | Never deployed (Canvas stopped at Lab 08). Losing half of a duplicate pair — `Lab09_XSS_SQLi` (kept, top-level) has more variants and a dedicated SQLi tool; this one is the shorter, less-developed draft. |
| `Lab10_DoS_Firewalls/` | Never deployed. Losing half of a duplicate pair — `Lab10_NetworkSecurity` (kept, top-level) has a richer 3-stage attack design (baseline + SlowLoris + UDP flood) vs. this folder's single flood scenario. |

**Still at top level, unchanged, because they're genuinely unused-but-good material with no numbering conflict:** `Lab09_XSS_SQLi/`, `Lab10_NetworkSecurity/`, `Lab11_IDS/`, `Lab12_MemoryVulns/`, `Lab13_SystemExecution/` — none of these topics shipped as a numbered lab in Spring 2026 (Canvas stopped at Lab 08), and nothing else claims their number slot. They're cited directly as optional starter material in several Fall 2026 project specs.
